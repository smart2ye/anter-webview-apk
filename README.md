# ANTER — APK WebView

تطبيق أندرويد بسيط يفتح ANTER كتطبيق كامل الشاشة عبر WebView.

## المزايا
- شاشة كاملة بدون شريط المتصفح.
- دعم الكاميرا والميكروفون (للمكالمات والريلز).
- دعم رفع الملفات والصور.
- دعم الإشعارات وفتح الروابط الخارجية.
- RTL كامل.
- Splash screen مع شعار ANTER.

## البناء
- تلقائي على GitHub Actions.
- الملف الناتج: تبويب Actions → آخر تشغيل → Artifacts.
